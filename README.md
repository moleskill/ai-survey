# Опрос «ИИ в школе»

Анонимный опрос для недели информатики: ученики отвечают на 20 вопросов, а администратор
входит через `/admin` и открывает `/report` с выводами и графиками. Скачать отчёт можно в PDF.

Стек: Next.js (App Router) + Supabase + Vercel. Язык интерфейса: русский.

## Как это устроено

```
app/page.jsx               страница опроса (по одному вопросу на экран, под телефон)
app/admin/page.jsx         вход администратора по почте и паролю из переменных окружения
app/report/page.jsx        отчёт, доступный только после входа администратора
app/api/submit/route.js    принимает ответы, проверяет их на сервере, пишет в Supabase
app/api/admin/*            создаёт и завершает защищённую cookie-сессию администратора
app/api/report/route.js    проверяет сессию, считает статистику, отдаёт только счётчики
components/Survey.jsx      логика опроса (пропуск вопросов, кнопки, отправка)
components/Charts.jsx      графики на HTML/CSS/SVG (без библиотек, печатаются в PDF)
lib/questions.js           ВСЕ вопросы и варианты ответов (единый источник)
lib/validate.js            серверная проверка ответов
lib/stats.js, findings.js  подсчёт цифр и текстовые выводы для отчёта
supabase/schema.sql        таблица responses
scripts/seed.mjs           фейковые ответы для проверки отчёта
```

Ответы в базу пишет только сервер (ключ `service_role` лежит в переменных окружения Vercel).
Из браузера к таблице обратиться нельзя: включена RLS и нет ни одной политики.

## 1. Supabase

1. Создай проект на supabase.com.
2. Открой **SQL Editor -> New query**, вставь содержимое `supabase/schema.sql` и нажми **Run**.
3. Открой **Project Settings -> API** и скопируй `Project URL` и ключ `service_role`
   (подойдёт и новый secret key). Ключ секретный: не публикуй его и не коммить в GitHub.

## 2. Запуск на своём компьютере

Нужен Node.js 20 или новее.

```bash
npm install
cp .env.example .env     # на Windows: copy .env.example .env
# открой .env и заполни SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, ADMIN_EMAIL, ADMIN_PASSWORD
npm run dev
```

- Опрос: http://localhost:3000
- Вход администратора: http://localhost:3000/admin

### Проверить, как выглядит отчёт

```bash
npm run seed            # добавить 150 фейковых ответов (npm run seed -- 300 для 300)
npm run clear-test      # удалить только фейковые ответы, настоящие не трогает
```

Обязательно запусти `clear-test` перед неделей информатики.

## 3. Деплой на Vercel

1. Залей папку в репозиторий на GitHub (`.env` в `.gitignore`, он не попадёт).
2. На vercel.com: **Add New -> Project**, выбери репозиторий.
3. В разделе **Environment Variables** добавь:
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `ADMIN_EMAIL`
   - `ADMIN_PASSWORD`
   - `NEXT_PUBLIC_BLOCK_REPEAT` = `false`
4. Нажми **Deploy**. Ссылку на сайт можно превратить в QR-код и повесить в кабинете информатики.

Если поменял переменные окружения, нужен новый деплой (Deployments -> Redeploy).

## Отчёт и PDF

Страница `/report` показывает: ключевые выводы, диаграммы по каждому из 20 вопросов,
использование ИИ по классам, рост числа пользователей по годам и среднее доверие по классам.
Кнопка **Скачать PDF** открывает печать браузера: выбери «Сохранить как PDF».
Если полосы графиков не видны, включи в настройках печати «Фоновая графика».
Кнопка **Обновить данные** подтягивает свежие ответы без перезагрузки.

## Как поменять вопросы

Вопросы лежат в `lib/questions.js`. Тексты и подписи вариантов можно менять свободно.
Если меняешь `value` вариантов или добавляешь вопрос, обнови и `supabase/schema.sql`
(CHECK-ограничения и колонки), иначе база отклонит ответы. Проще всего пересоздать
таблицу: `drop table public.responses;` и снова запустить schema.sql (данные при этом удалятся).

## Что стоит знать

- **Повторные ответы.** По умолчанию один браузер может пройти опрос несколько раз
  (на общих школьных компьютерах это нужно, там за одним ПК сидят разные ученики).
  Защита от двойной отправки одного и того же ответа есть. Если хочешь ограничить
  «один браузер = один ответ», поставь `NEXT_PUBLIC_BLOCK_REPEAT=true` и передеплой.
  Это защита от случайных повторов, а не от намеренной накрутки.
- **Спам.** Адрес `/api/submit` открыт для всех. Для школьного мероприятия этого достаточно;
  при необходимости включи Rate Limiting в Vercel Firewall.
- **Пауза Supabase.** Бесплатные проекты ставятся на паузу после недели без активности.
  Зайди в панель Supabase перед неделей информатики и проверь, что проект работает.
- **Малые группы.** Если в каком-то классе мало ответов, проценты по нему прыгают.
  В отчёте рядом с каждым классом указано число ответов.
- **Анонимность.** В таблице нет имён, IP-адресов и других данных о человеке. Токен отправки
  случайный и нужен только для защиты от двойного нажатия.
