# Школьный сайт «Лицей и ИИ»

Сайт к неделе информатики и учебному году 2026–2027: концепция года, план мероприятий,
фотогалерея (фото добавляет администратор) и анонимный опрос школьников про ИИ с автоматическим
отчётом и графиками.

Стек: Next.js (App Router) + Supabase + Vercel. Язык интерфейса: русский.

## Страницы

| Адрес | Что там | Кто видит |
| --- | --- | --- |
| `/` | Главная: тема, цель, задачи и направления года, ход выполнения плана, ближайшие мероприятия, свежие фото | все |
| `/plan` | План мероприятий по 5 разделам, статусы, даты, ссылки на фото | все |
| `/gallery` | Фотогалерея по мероприятиям с просмотром на весь экран | все |
| `/survey` | Анонимный опрос (20 вопросов) | все |
| `/admin` | Вход и панель администратора | администратор |
| `/admin/events` | Добавление, правка, скрытие, удаление мероприятий, отметка «проведено» | администратор |
| `/admin/gallery` | Загрузка фото к мероприятиям, подписи, перенос между альбомами, удаление | администратор |
| `/admin/concept` | Тема, цель, задачи и направления работы на главной | администратор |
| `/report` | Отчёт по опросу, скачивание в PDF | администратор |

Опрос переехал с главной страницы на `/survey`. Если вы уже раздали QR-код или ссылку на корень сайта,
замените их на `/survey`.

## Как это устроено

```
app/page.jsx, plan/, gallery/   публичные страницы (данные читаются на сервере)
app/survey/page.jsx             опрос
app/admin/**                    вход и страницы администратора
app/api/admin/login, logout     сессия администратора (cookie)
app/api/admin/session           проверка «я вошёл?»
app/api/admin/events            мероприятия: чтение, создание, правка, удаление
app/api/admin/concept           концепция года
app/api/admin/photos            фото: список, загрузка, подпись/альбом, удаление
app/api/submit, report          ответы опроса и отчёт (как раньше)
components/                     Site*, Home/Plan/GalleryView, OrbitArt (иллюстрация), Icon, AdminShell, Survey, Charts
lib/sections.js                 разделы плана и статусы
lib/content.js, viewModels.js   чтение контента из базы и подготовка данных для страниц
lib/validateContent.js          серверная проверка всего, что вводит администратор
lib/imageCompress.js            сжатие фото в браузере перед загрузкой
supabase/schema.sql             таблица responses (опрос)
supabase/02-school-site.sql     таблицы events, photos, site_content и хранилище фото
```

Все записи в базу и хранилище делает только сервер (ключ `service_role` лежит в переменных окружения).
Из браузера к таблицам обратиться нельзя: включена RLS и нет ни одной политики. Каждый админский
API проверяет подписанную cookie-сессию, без входа отвечает 401.

## 1. Supabase

1. Создай проект на supabase.com.
2. **SQL Editor -> New query**: вставь `supabase/schema.sql` и нажми **Run** (таблица опроса).
3. Там же вставь `supabase/02-school-site.sql` и нажми **Run**. Он создаёт таблицы сайта,
   публичное хранилище `gallery` для фото, стартовую концепцию года и 23 мероприятия из плана лицея.
   Скрипт можно запускать повторно: уже добавленные данные он не дублирует и не затирает.
4. **Project Settings -> API**: скопируй `Project URL` и ключ `service_role`
   (подойдёт и новый secret key). Ключ секретный: не публикуй его и не коммить в GitHub.

Если сайт уже работает (опрос развёрнут), выполни только пункт 3.

## 2. Запуск на своём компьютере

Нужен Node.js 20 или новее.

```bash
pnpm install            # или npm install
cp .env.example .env    # на Windows: copy .env.example .env
# заполни SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, ADMIN_EMAIL, ADMIN_PASSWORD
pnpm dev                # или npm run dev
```

Новые переменные окружения не понадобились: всё работает на тех же `SUPABASE_URL`,
`SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`.

## 3. Деплой на Vercel

Залей изменения в репозиторий, Vercel соберёт сайт сам. Если менял переменные окружения,
нужен новый деплой (Deployments -> Redeploy).

## Оформление

Дизайн продолжает стиль опроса: те же цвета (тёмно-зелёный, лаймовый акцент), шрифты Unbounded и Golos Text.
Публичные страницы собраны в `app/site.css`, а исходные стили опроса и отчёта остались в `app/globals.css`.
Иллюстрация на главной (`components/OrbitArt.jsx`) нарисована на SVG и CSS, без картинок: вокруг светящегося ядра
вращаются орбиты, а на них подписаны пять разделов плана. Анимации отключаются, если у посетителя включено
«уменьшить движение» в системе. Цвета акцента можно поменять в переменных `:root` файла `app/globals.css`.

## Как пользоваться админкой

**Мероприятия.** `/admin/events` -> «Добавить мероприятие». Название и раздел обязательны, остальное по желанию:

- «Когда (текстом)» показывается на сайте как есть: «12–17 октября», «январь».
- «Дата начала» нужна для сортировки внутри раздела и для блока «Ближайшие мероприятия» на главной
  (в нём попадают мероприятия со статусом «Запланировано» и датой не раньше сегодняшней).
- Кнопка «Проведено» отмечает мероприятие, и на главной растёт полоса выполнения раздела.
- «Показывать на сайте» выключает мероприятие для посетителей вместе с его фото.

**Фото.** `/admin/gallery`: выбери альбом (мероприятие или «Общие фото»), выбери файлы (можно много сразу
и прямо с телефона) и нажми «Загрузить». Перед отправкой фото уменьшаются до 1800 px по длинной стороне
и сохраняются в JPEG, поэтому тяжёлые снимки с камеры не проблема. У каждого фото можно поменять подпись,
перенести в другой альбом или удалить (из хранилища оно удаляется тоже).

**Концепция.** `/admin/concept`: тексты главной. Задачи пишутся по одной в строке. Направления работы:
по строке в формате `Название | Мероприятия`.

Стартовые тексты и список мероприятий взяты из фотографий документов лицея. Рукописные правки на них
читались не везде, поэтому даты, ответственных и статусы заполни в админке, а формулировки проверь.

## Опрос и отчёт

Как и раньше: вопросы лежат в `lib/questions.js`, отчёт открывается на `/report` после входа, скачивается
в PDF через печать браузера. Тестовые ответы: `pnpm seed` и `pnpm clear-test` (перед неделей информатики
обязательно запусти `clear-test`).

## Что стоит знать

- **Фото учеников.** Сайт закрыт от поисковиков (`noindex`), но фото открываются каждому, у кого есть
  ссылка. Проверь, что на публикацию фото есть согласие родителей или школы.
- **Одна учётная запись.** Администратор один, данные берутся из `ADMIN_EMAIL` и `ADMIN_PASSWORD`.
  Сессия живёт 8 часов. Чтобы дать доступ второму человеку, придётся делиться этим паролем.
- **Размер фото.** Сервер принимает файл до 4 МБ (ограничение Vercel на запрос 4,5 МБ). После сжатия
  в браузере фото обычно весят 0,3–1 МБ. Форматы: JPG, PNG, WebP. HEIC с iPhone Safari при выборе
  файла обычно сам превращает в JPEG; если браузер не смог открыть фото, покажет ошибку.
- **Бесплатные лимиты Supabase.** В хранилище бесплатного плана помещается около 1 ГБ (это сотни
  сжатых фото). Проект ставится на паузу после недели без активности: перед неделей информатики
  зайди в Supabase и проверь, что он работает.
- **Опрос.** Повторные ответы, защита от спама и анонимность описаны в предыдущей версии README:
  по умолчанию один браузер может пройти опрос несколько раз, чтобы за одним школьным компьютером
  могли отвечать разные ученики (`NEXT_PUBLIC_BLOCK_REPEAT=true` включает ограничение).
